Data Pipeline Development
Internship Task 1 - CodTech Data Science Internship
Objective
Develop an ETL (Extract, Transform, Load) pipeline using Pandas and Scikit-Learn for data preprocessing and transformation.

Dataset
IBM Telco Customer Churn Dataset

Steps Performed
Loaded the dataset using Pandas.
Cleaned the data by removing unnecessary columns.
Converted data types and handled missing values.
Encoded the target variable.
Split the dataset into training and testing sets.
Identified numerical and categorical features.
Applied Standard Scaling to numerical features.
Applied One-Hot Encoding to categorical features.
Created a preprocessing pipeline using Scikit-Learn.
Transformed the dataset and saved the outputs.
Tools Used
Python
Pandas
NumPy
Scikit-Learn
Joblib

churn_pipeline.pkl
